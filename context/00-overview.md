## What is Mezo?

Mezo is a Bitcoin-native sidechain (EVM-compatible, built on Cosmos SDK / Evmos fork) designed as the "Bitcoin economic layer." It lets BTC holders deposit Bitcoin as collateral and borrow MUSD — a 100% Bitcoin-backed stablecoin — at fixed 1–5% APR. The chain uses BTC as gas. Mezo's ve-tokenomics model (inspired by Curve/Aerodrome) lets users lock BTC for veBTC to earn BTC-denominated fees from chain activity. MEZO token is the multiplier/coordination layer.

## Key Primitives Available

- **MUSD smart contracts:** github.com/mezo-org/musd (Solidity, MIT-ish)
- **@mezo-org/passport:** RainbowKit-based wallet connector supporting both Bitcoin wallets (Xverse, Unisat) and EVM wallets (MetaMask)
- **Testnet RPC:** https://rpc.test.mezo.org (Chain ID: 31611)
- **Mainnet RPC:** Multiple providers (Boar, Imperator, Validation Cloud, dRPC)
- **Block Explorer (testnet):** explorer.test.mezo.org
- **Faucet:** faucet.test.mezo.org
- **Hardhat/Foundry compatible:** Yes, standard EVM toolchain
